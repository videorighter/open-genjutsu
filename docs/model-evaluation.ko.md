# 실제 모델 평가: 총 $10

이번 검증에 승인된 유료 API 총액은 $10이다. 아직 유료 생성은 실행하지 않았다. 공개 HTTPS 스테이징, 사용할 계정의 공급자 키와 실제 움직임이 있는 테스트 영상이 준비된 뒤 진행한다. 로컬 색상 영상의 FFmpeg 성공은 모션 모델의 품질 증거로 쓰지 않는다.

## 실행 전 확인

1. [Cloudflare 스테이징](cloudflare-staging.ko.md)을 준비하고 해당 평가 계정에 OpenRouter 및 fal 키를 등록한다. 영상 공급자 계정은 OpenRouter와 별개다.
2. 공급자 자동 충전을 끄고 키/계정 지출 제한을 설정한다. 공급자별 한도 합계를 $10 이내로 배정한다. 잔액이 있다고 지출 제한이 보장되는 것은 아니므로 공급자의 초과 청구 정책도 확인한다.
3. 테스트 직전의 단가, 입력 영상 길이, 해상도, 최소 청구 단위, 실패/취소 과금을 확인한다. 상한을 입증할 수 없는 요청은 보내지 않는다. `$10`은 프런트엔드의 유료 동의 체크박스나 예상 비용으로 강제되지 않는다.
4. 호출별 상한과 실제 청구를 개인 평가 장부에 기록한다. 비밀 키·서명 URL을 저장소에 넣지 않는다. 여러 계정/브라우저에서 동시에 시험하지 않는다.

계획 배분은 OpenRouter $0.50, Wan $2.50, Kling $3, VACE $3, 예비 $1이다. 고정된 약속 가격이 아니라 호출 가능 여부를 결정하는 **각 항목의 최대 배정액**이다. 현재 가격이 배정액을 넘으면 입력을 줄이거나 그 호출을 보류한다. 예비 금액 사용 전 이미 청구된 금액과 진행 중인 호출의 최대 비용을 함께 계산한다.

## 비교 순서

| 대상 | 평가할 기능 | 입력·관찰 |
| --- | --- | --- |
| OpenRouter Qwen VL → Dolphin/Hermes | 이미지 분석과 프롬프트 설계 | 업로드 영상의 샘플 프레임 설명, 사용자 지시 반영, 실제 사용하는 토큰 상한 |
| Wan Animate move/replace | 프롬프트 없는 캐릭터 모션 전이 | 동일한 3~5초 원본과 참조 이미지, 동작 유지와 캐릭터 일관성 |
| Kling Motion Control | 방향 기준과 오디오 옵션 | 같은 원본/참조, video 방향 우선, image 방향은 10초 이하 |
| VACE pose/inpainting | 프롬프트 및 제한된 영역 편집 | pose 기본 비교 후 마스크가 준비됐을 때만 inpainting 실행 |

최초에는 모델당 한 번씩 실행한다. 새 모델 fallback이나 실패 재실행은 자동으로 진행하지 않는다. 접수 응답 유실은 운영 현황에서 확인하며 공급자 접수 ID로 이어 조회한다.

실제 품질 입력은 정면 단순 동작, 빠른 팔·다리 동작, 회전, 가림/다인 장면, 카메라 이동의 다섯 유형으로 준비한다. 첫 예산에서는 대표 1개를 공통 입력으로 비교하고 나머지 유형은 예산에 맞는 추가 호출만 수행한다. 모든 모델·모든 유형을 $10으로 검증했다고 표현하지 않는다.

각 결과는 원본 동작 보존, 인물 외형 보존, 손·발·얼굴 오류, 프레임 간 깜빡임, 배경 안정성, 오디오·길이, 처리 시간, 실제 비용을 기록한다. 공급자 작업 ID와 앱 작업 ID를 연결하되 개인 평가 자료에 보관한다. 출력 MP4 다운로드와 `ffprobe`를 확인하고, 최종 추천은 결과를 사람이 비교한 후 정한다.

## 현재 연구 근거

공유 카탈로그 `models/catalog.json`은 2026-10-08에 OpenRouter 공개 모델 목록과 fal의 Kling/VACE API 입력 문서를 확인한 결과다. 확인한 문서 URL은 각 모델의 `source`에 기록한다. 공개 목록과 스키마 확인은 실제 생성·가격 검증과 구분하며, 외부 모델의 `generationVerified`는 아직 `false`다. 기본 프롬프트 후보 Dolphin/Hermes도 공급자별 정책·라우팅과 실제 결과를 확인한 뒤 채택 범위를 조정한다. 사용자 지정 모델과 다른 API는 계속 교체할 수 있다.
