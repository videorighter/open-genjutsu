# 웹 스튜디오와 서버 데이터

기본 모드는 로그인하는 서비스이며 `src/ServiceApp.tsx`가 세션·프로젝트·키·미디어·작업 내역을 관리한다. `src/App.tsx`는 노드 편집과 실행 전 확인을 담당한다. `npm run dev:editor`는 서버 없이 편집하는 별도 모드다.

프로젝트 JSON은 `version: 1`, `title`, `nodes`, `edges`로 구성된다. 노드는 ID, 위치, kind·label·provider·model·prompt·temperature·seed·resolution과 선택적인 assetId·미디어 메타데이터·providerInput을 가진다. 생성 노드의 provider는 `openrouter`, 입력 노드와 결과 내보내기는 `local`이다. 이전 버전의 fal·Replicate·GPU·Custom 노드는 서버 프로젝트와 JSON 가져오기 모두 해당 단계의 OpenRouter 기본 모델로 바꾸고 endpoint는 버린다. API 키와 미디어 bytes는 포함하지 않는다. JSON의 assetId는 서버 미디어를 가리키므로 다른 서버에 가져오면 파일을 다시 업로드해야 한다.

서비스는 계정별 프로젝트와 revision을 PostgreSQL에 저장한다. 편집을 550ms 지연 후 직렬로 저장하며 서버 확인 후 저장 완료를 표시한다. 아직 확인되지 않은 수정이 있으면 페이지 이탈을 경고한다. 프로젝트 변경·로그아웃·작업 시작 전에도 저장을 기다린다. 다른 탭의 변경으로 revision이 다르면 409로 덮어쓰기를 막는다. JSON을 내보내 수정 내용을 보관한 뒤 서버 버전을 다시 불러온다.

입력 미디어는 업로드 시 실제 이미지/영상 형식과 길이·크기를 검사하고 계정별 불변 asset ID로 저장한다. Worker가 결과를 가져오고, 결과 내보내기는 FFmpeg로 고른 오디오(원본 오디오·생성 오디오·무음)를 넣어 새 미디어를 만든다. 이미지 결과물은 연결된 이미지를 그대로 쓴다. 원본 영상 노드에 구간을 정하면 원본 영상 단계가 그 부분을 잘라 새 미디어로 저장하고, 이후 단계(장면 분석, 모션 전이, 원본 오디오)는 모두 이 구간만 쓴다. 일반 다운로드는 로그인과 미디어 소유권을 검사한다. OpenRouter 입력은 공개 HTTPS에서는 제한 시간의 서명 URL, 그 밖에는 요청에 포함한 data URL을 사용한다. 원본 영상은 공개 HTTPS에서만 모델에 보낼 수 있다.

작업을 시작하면 서버가 프로젝트 구성·모델 지원·입력 미디어·API 키·한도를 검증한다. 클라이언트가 계산한 순서나 경고를 신뢰하지 않는다. 확정한 graph snapshot, request_key와 각 단계의 원장을 DB에 저장한 뒤 dispatcher가 고정 Temporal Workflow ID로 시작한다. 실행 중 편집은 이미 접수한 snapshot을 바꾸지 않는다.

모달이 열린 동안 배경을 inert로 처리하고 캔버스 삭제 단축키를 비활성화한다. Tab을 대화상자 안에 유지하고 Escape로 닫은 뒤 포커스를 복원한다. 서비스 화면에서 비밀번호와 API 키는 폼 메모리에만 두고 저장 후 지운다.

오프라인 편집기는 localStorage 자동 저장과 JSON 교환을 제공한다. 이 모드의 미디어는 현재 세션 미리보기이고 서버에 저장되지 않는다. 실행 전 확인에서 **확인 내용 내보내기**를 할 수 있지만 생성 API를 호출하지 않는다.

운영 구성과 모델 옵션·공급자 연결 계약은 [운영 가이드](operations.ko.md), [공급자 계약](provider-contract.ko.md)을 참고한다.

공급자는 노드 종류별로 고정되며 **추천 모델**은 선택한 노드 종류의 모델만 보여준다. 서비스 모드의 OpenRouter 모델 ID 입력란은 서버의 OpenRouter 카탈로그에서 노드 종류에 맞는 모델과 가격 요약을 제안한다. 영상 모델의 해상도·길이·화면 비율·참조 이미지 사용 방식은 노드 설정의 **모델 옵션**에서 모델이 지원하는 값만 선택할 수 있고, **고급 옵션(JSON)**에서 직접 고칠 수도 있다. 원본 영상을 받는 모션 전이·영역 편집의 길이는 고를 수 없다. 서버가 구간 길이(0.1초 단위)를 덮는 가장 짧은 허용 길이로 정하고 생성 결과를 구간 길이로 자르며, 구간이 모델의 최대 길이보다 길면 같은 길이의 조각 n개(n = 구간 ÷ 최대 길이 올림)로 나눠 단계 하나 안에서 차례로 생성하고 이어 붙인다(나눠 생성). 둘째 조각부터는 앞 조각의 마지막 프레임을 참조 이미지로 함께 보낸다(참조 이미지 사용이 '인물·스타일 참조'일 때, `docs/adr/0001`). 실행 전 확인은 조각 수·조각당 비용 기준·시간을 알리고 예상 비용에 조각 수를 곱하며, 작업 내역은 '조각 3/6'처럼 진행을 보여 준다. 조각이 실패하거나 작업을 취소하면 완료된 조각을 이은 부분 영상을 미디어 보관함에 남기고 작업 내역에 링크한다. 조각용 원본·결과 미디어는 단계가 끝나면 지운다. 다음 조각 접수도 접수 의도를 먼저 저장하고 자동으로 다시 보내지 않으며, 접수가 불확실하면 확인 대기가 된다. 운영자가 생성 요청 ID로 복구하면 그 조각부터 이어 간다. 작업 제한 시간 기본값은 6시간이다. 장면 분석·프롬프트 작성 노드의 Temperature도 모델 옵션에 있으며, Seed는 모델이 지원할 때만 표시한다. **이미지 생성** 노드의 결과는 계정 미디어로 저장되어 모션 전이·영역 편집 노드의 참조 이미지로 연결된다. 실행 전 확인은 예상 비용과 OpenRouter 영상의 취소 불가를 함께 표시한다.
